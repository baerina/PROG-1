# PROG-1
**C Programming Practice**

A collection of my beginner-level C programming exercises and practice problems. This repository is where I store the programs I create while learning the fundamentals of C programming.

**About the Project**

This project was created to practice and improve my understanding of the C programming language.
Each program contains the problem/question first, followed by the C code and a short explanation of how the program works.

**Requirements**

To run these programs, you need:

- A C compiler: https://www.programiz.com/c-programming/online-compiler/
- A code editor or IDE, such as Visual Studio Code
- A terminal or command prompt
